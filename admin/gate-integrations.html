📋 Review checklist when a request lands

  1. Triage — is this protocol something we can speak? (TCP/IP HTTP yes, OSDP feasible, Bluetooth-only RFID probably no.)
  2. Risk assessment — vendor's documentation? closed-source binary? prior art on GitHub? Estimated dev time.
  3. Quote — pick: (a) Decline · (b) Accept at standard $250+$25 if you're confident · (c) Custom quote $500–$2,000+ for new development
  4. Pilot — when accepted, schedule on-site visit. Test on tenant's actual panel. Get sign-off.
  5. Promote — once working, promote the request to a Verified Template so future clubs with the same panel are one-click.

📋 Provisioning workflow (updated 2026-05-22)

  1. Requested → tenant clicked "Request integration." You get an email + Slack-style admin task with their name + phone. Call them — no invoice goes out automatically anymore.
  2. Verify integration → confirm panel is compatible, agree on plan, ship the Pi bridge, run on-site test.
  3. Active → bridge phones home, flip status to active. Members can unlock.
  4. Send invoice → hit 💸 Send invoice on the tenant's row. Enter amount + optional override email. Tenant gets an email + in-app banner. Status is unaffected (orthogonal column).
  5. Mark paid → when the payment lands (Venmo / check / wire), click ✓ Mark paid. Recorded in the audit log; the tenant sees a "paid" pill.
