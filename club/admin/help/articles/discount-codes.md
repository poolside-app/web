---
title: "How do I make a discount code, like an early-bird price?"
category: "Money"
---

A discount code takes money off a family's dues. Families type it in **Have a discount code?** when they sign up or renew.

### Make a code

1. Go to **Money → Payments → Money setup → Discounts**.
2. Fill in:
   - **Code families type**, like EARLYBIRD.
   - **What it's for (optional)**, like Early bird.
   - **Discount**: a dollar amount or a percent.
   - **Last day to use it (optional)**.
   - **How many families can use it (blank for no limit)**.
   - **Show it on the member app's home screen**, to advertise it to your members.
3. Tap **Save code**.

Each code shows how much it takes off, until when, and how many families have used it. Tap **Switch off** to stop a code early.

### One discount per family

If a family has a code and also came through a friend's referral link, only one counts, whichever saves more. They're told which one was used.

> Tip: For an early-bird price, set the last day and tick **Show it on the member app's home screen**. Members see it on their home screen until it ends.
