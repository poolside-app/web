---
title: "What is the code in a Venmo payment?"
category: "Money"
---

Every "Pay with Venmo" button in Poolside opens Venmo with the amount and a note already filled in, like "Cabana Club 2027 dues - Smith - #K7Q2". The 4 characters after the # are that payment's code.

### Why it's there

A family's Venmo account is often in one parent's name, or a different last name, so the name alone doesn't tell you who paid. The code does: each signup, party and keyfob payment has its own.

### Where you see it

- Next to the family on **Members → Signups**, **Calendar → Parties** and **Members → Keyfobs & Access**.
- In **💸 Venmo to check** on **Money → Payments**, where you confirm several at once. See "How do I confirm a Venmo, check or cash payment?"

### If a family typed their own note

Match by amount and name instead, and confirm it the same way. The code is a help, not a requirement.

> Tip: Search your Venmo history for the code (like K7Q2) to find a payment fast.
