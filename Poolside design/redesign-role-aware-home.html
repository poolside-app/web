What's the same

Both Margaret and Rick land on Home with the same shell — greeting, "What needs you" queue, two-stat strip. Same component, same pattern.

What changes

The nav only contains tabs they can act on (no greyed-out Money for Rick). The queue items are filtered by role tag. The stat strip shows the metrics that matter to their job. No "you don't have permission" walls — they just don't see what isn't theirs.

Implementation: every action-queue item carries a role: 'money' | 'people' | 'comms' | 'calendar' | 'club' tag. The Home page reads currentAdmin.roles[] and filters. Multi-role admins (e.g. Rick is also Volunteer coordinator) see the union of items. Board chair sees everything, optionally grouped by role ("Treasurer should handle: 4 · Comms should handle: 3"). Same Home component, same React tree — only the data filters change.
